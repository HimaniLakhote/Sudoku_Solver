# 🧩 Sudoku Solver & Generator

An intelligent Python-based **Sudoku Solver and Puzzle Generator** that combines classic backtracking with advanced **Constraint Satisfaction Problem (CSP)** techniques to efficiently solve Sudoku puzzles.

The project supports:

- 🎲 Random Sudoku puzzle generation
- ✍️ Custom puzzle input
- 🧠 AI-based intelligent solving algorithms
- 🎥 Animated terminal visualization
- 📊 Performance analysis and solving statistics

---

# 📌 Overview

This project demonstrates how Artificial Intelligence techniques can be applied to solve logical puzzles efficiently. The solver uses optimized heuristics and constraint propagation methods to reduce unnecessary search operations and improve solving performance.

The system integrates:

- ✅ Backtracking Algorithm
- ✅ Constraint Satisfaction Problem (CSP)
- ✅ Minimum Remaining Values (MRV)
- ✅ Least Constraining Value (LCV)
- ✅ Forward Checking

These techniques help the solver make smarter decisions while solving complex Sudoku boards.

---

# ✨ Features

## 🎲 Sudoku Puzzle Generator

Generate random Sudoku puzzles with adjustable difficulty levels by intelligently removing cells from a fully solved board.

### Supported Difficulty Levels
- Easy
- Medium
- Hard

---

## 🧠 Intelligent Sudoku Solver

The solver uses advanced AI-inspired techniques for efficient problem-solving.

| Technique | Description |
|---|---|
| **Backtracking** | Recursive depth-first search algorithm |
| **MRV Heuristic** | Selects the cell with minimum remaining possible values |
| **LCV Heuristic** | Chooses the least constraining value first |
| **Forward Checking** | Removes invalid future possibilities early |

These optimizations significantly reduce solving time and unnecessary computations.

---

# 🎥 Terminal Visualization

The project includes a real-time animated solving visualization in the terminal.

### Visualization Features
- Live solving animation
- Highlighted active cell
- Step-by-step solving process
- Clean Sudoku board formatting
- Colored terminal output using ANSI escape codes

This makes the solving process easier to understand and visually engaging.

# 📊 Performance Metrics

After solving a puzzle, the system displays:

- ⏱️ Total solving time
- 🔄 Number of recursive steps
- ↩️ Number of backtracks
- ✅ Final solved board

These metrics help analyze algorithm efficiency and optimization performance.
